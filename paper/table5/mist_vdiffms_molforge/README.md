# Table 5 · MIST vDiffMS + MolForge (diagnostic rows; Table 4)

| | Acc@1 | MCES@1 | Tanimoto@1 | Acc@10 | MCES@10 | Tanimoto@10 | Encoder Tanimoto |
|---|---|---|---|---|---|---|---|
| batch size 1 (`mist_vdiffms_molforge_bs1`) | 10.73% | 22.15 | 0.37 | 14.48% | 17.88 | 0.41 | 0.457 |
| batch size 24, inflated (`mist_vdiffms_molforge_bs24`) | 31.75% | 12.30 | 0.68 | 40.55% | 9.80 | 0.74 | 0.812 |

These rows show how the MIST padding-mask bug (paper Sec. 6.1.1) inflated the original
MIST + MolForge result. Upstream attention adds the raw boolean padding mask
(`attn += attn_mask`), so padded positions get +1 instead of -inf. The DiffMS
checkpoint was trained with that bug and learned to use zero-padded positions. At batch
size 1 there is no padding and the bug is dormant. At batch size 24 every spectrum
shorter than the longest in its batch is padded, and the posteriors are inflated.

**Source.** [`encoders/mist/diffms.py`](../../../src/msms_models/encoders/mist/diffms.py),
which wraps MIST as released with
[DiffMS](https://github.com/coleygroup/DiffMS) (`9d9f4fd`, MIT;
[vendor notes](../../../src/msms_models/encoders/mist/vendor/README.md)), feeds
[`models/de_novo/molforge`](../../../src/msms_models/models/de_novo/molforge/)
([knu-lcbc/MolForge](https://github.com/knu-lcbc/MolForge), CC BY-NC-SA 4.0). The
original pipeline is `mist-molforge-benchmark --config configs/spec2mol_benchmark_msg.yaml
--batch-size 24` from MIST-MolForge `7736e4a`, run once with the buggy line and once with
it corrected.

**What runs.** The DiffMS MIST checkpoint encodes each spectrum's subformula tree. The
4096-bit posterior is thresholded at 0.172 and MolForge decodes ten beams. Spectra are
encoded in the frozen cohort order, `encoder_batch_size` consecutive spectra per pass,
which preserves the original `DataLoader(shuffle=False)` batches.

| Config | `attention_padding` | `encoder_batch_size` |
|---|---|---|
| [`config-bs1.yaml`](config-bs1.yaml) | `masked` (-inf on padding) | 1 |
| [`config-bs24.yaml`](config-bs24.yaml) | `additive-bool` (historical +1) | 24 |

At batch size 1 the two padding modes agree, so `bs1` is also the corrected encoder.
The encoder Tanimoto in the table is the mean, over the cohort, of the Tanimoto between
the thresholded posterior (≥ 0.172) and the target's Morgan fingerprint (radius 2,
4096 bits, RDKit `GetMorganFingerprintAsBitVect`). The evaluator does not report it.

**Cohort.** These rows were evaluated on 17,082 of the 17,556 MassSpecGym test spectra.
The DiffMS/MIST-MolForge loader keeps a spectrum only if its target contains nothing
outside {C, O, P, N, S, Cl, F, H}, which drops 474 spectra. The selection used the
target structures, so it is frozen here as [`cohort_ids.txt`](cohort_ids.txt) (sha256
`75adb0b6…45ee55`), in the order of the DiffMS `labels.tsv`. The list was regenerated by
running the original `get_paired_spectra` and `PresetSpectraSplitter` code. It equals
the spectrum order of the archived MIST-MolForge predictions. `run.sh` selects these
spectra from `data/msg/queries.jsonl` and checks the result (sha256 `319992d5…835f40`).
Inference reads no target structures.

**Environment.** `pip install -c environments/generation.txt -e '.[molforge,mces]'`
(PyTorch, SentencePiece, RDKit).

**Bootstrap.** Table 5 prints no intervals.

**Reproduction status.** *Encoder verified on a subset; the decode and metrics have not
been rerun.*

- The first 240 cohort spectra (ten batches of 24) were encoded with this package and
  with the original MIST-MolForge `7736e4a` code, with and without the buggy line, on the
  same CPU. Thresholded bits agree on every spectrum in all four settings. Posteriors
  agree exactly for batch size 24; for batch size 1 the largest difference is 1.1e-5.
- `msms-models predict --config config-bs24.yaml --limit 24` produced the same posterior
  cache as the original buggy code on those 24 spectra, with the proposed registry entry
  for `diffms_features` applied (max difference 0; 1,165 bits differ from masked
  padding). Decoding was not completed: on CPU it took about 30 s per spectrum.
- On these 240 spectra the encoder Tanimoto is 0.599 with masked padding or batch size 1
  (the archived corrected run gives 0.599 on the same spectra, with identical on-bits).
  With additive-bool padding at batch size 24 it is 0.952. Subset values are not
  comparable with the printed full-cohort 0.457 and 0.812.
- Archived full-cohort encoder values: 0.4574 for the corrected encoder (several
  MIST-MolForge runs). A later padding-mode analysis by the original author gives 0.4574
  (masked) and 0.8053 (buggy, batch size 24). The printed 0.812 comes from the
  MIST-MolForge README and has not been matched by any archived run.
- No archived predictions exist for the decoder runs behind 10.73% and 31.75%. The
  original benchmark reported metrics after canonicalizing SMILES, dropping invalid ones
  and deduplicating them. It matched InChI without stereochemistry and computed MCES with
  threshold 30. The `table5` protocol here keeps the raw beam slots and uses InChIKey-14
  and MCES threshold 15, so `compare.py` may not reproduce the printed values exactly
  even if decoding matches.

## Run

From the repository root:

```bash
bash paper/table5/mist_vdiffms_molforge/run.sh
```

Set `DEVICE=cuda:0` for GPU inference and `OUT=...` to choose the parent output
directory. The original decode took about 9 GPU-hours per setting. `run.sh` builds the
cohort manifest, then predicts, evaluates with the fixed `table5` protocol and runs
[`compare.py`](../../compare.py) for both rows. It exits nonzero if either row differs.
