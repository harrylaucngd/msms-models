# Assets

Dataset files, model weights, tokenizers and derived features are explicit inputs.
The [resource inventory](../src/msms_models/artifacts.json) records their providers.
Each method guide identifies the subset it needs. The configurations are usable
with compatible local assets; several exact experimental assets are not yet
publicly downloadable.

Availability checked 2026-10-20:

| Resource | Provider / preparation | Availability |
|---|---|---|
| MSG spectra, split labels and candidate pools | [Official MassSpecGym](https://huggingface.co/datasets/roman-bushuiev/MassSpecGym); `msms-models download msg --output data --candidates formula` | Pinned revision and verified hashes included in this library |
| MIST MSG/CANOPUS source and compact features | [coleygroup/MIST catalog](https://github.com/coleygroup/MIST/blob/main/src/mist/artifacts.json) | Upload pending; download URLs and checksums are null |
| MIST noaug/aug and GLACIER checkpoints | [coleygroup/MIST](https://github.com/coleygroup/MIST) | Upload pending; matching local assets are required meanwhile |
| MolForge decoder and two SentencePiece models | [MolForge](https://github.com/knu-lcbc/MolForge) | Exact tested hashes are pinned in the normal configurations; public URLs for this particular triplet have not been verified |
| MS-GPT decoder, SAFE tokenizer and adapters | [MS-GPT](https://github.com/VIKI623/MS-GPT), [asset bundle](https://pan.sjtu.edu.cn/web/share/8f63823e4d82280636e537d1c789128d), [authorized mirrors and download commands](../src/msms_models/methods/ms_gpt/README.md) | Public versioned mirrors; pair each adapter with its encoder and calibration |
| FRIGID decoder and ICEBERG pairs | [FRIGID](https://github.com/coleygroup/FRIGID), [checkpoint archive](https://zenodo.org/records/19685145) | Public 2.8 GB archive, downloaded and checksum-checked during validation |
| FRIGID SAFE tokenizer and length predictor | [Length-model training](https://github.com/coleygroup/FRIGID/tree/main/token_models) and the matching SAFE tokenizer | Not included in that archive; obtain the exact original assets or train explicitly using the upstream procedure |
| ICEBERG generator/intensity pair | [ms-pred](https://github.com/coleygroup/ms-pred) | Use the matching dataset/architecture pair; the generic upstream release is not proof of the exact manuscript weights |
| NN index | `msms-models fit-nn` on training and validation data | Generated locally; no checkpoint download required |
| Fingerprint posterior cache | Selected MIST encoder and compact features | Generated by inference and reusable by conditioned methods |
| MS-GPT calibration | Official calibration for the encoder/adapter, or upstream training procedure | Must record the training split and encoder identity |
| FOAM seed pool | Explicit generator outputs and frozen database candidates | Caller-supplied, with a source manifest |

The FRIGID archive contains `DLM.ckpt`, four ICEBERG checkpoints and two historical
MIST checkpoints. It does **not** contain the SAFE tokenizer, NGBoost predictor or
feature list. Replacing those auxiliary assets changes the experimental identity.

A null resource URL means the download is unavailable. It is not an existing
release with an omitted link. Synthetic MIST training caches are unnecessary for
ordinary inference. Exact manuscript runs additionally need the frozen preprocessing
and asset identities described in the [results note](paper-results.md).

## Local file layout

The configurations use the following layout; editing their paths is also supported:

```text
checkpoints/
  mist_msg_noaug.ckpt
  mist_msg_aug.ckpt
  mist_canopus_noaug.ckpt
  mist_canopus_aug.ckpt
  glacier_msg.ckpt
  molforge/{decoder.pth,source.model,target.model}
  ms-gpt/decoder/ms_gpt_mlm.pt
  ms-gpt/{msg,canopus}-encoder/mist_{massspecgym,nplib1}.pt
  ms-gpt/tokenizer.json
  ms-gpt/adapters/{msg,canopus}/
  frigid/{decoder.ckpt,tokenizer.json}
  frigid/{msg,canopus}_length.joblib
  frigid/{msg,canopus}_length_features.json
  iceberg/{msg,canopus}_{generator,intensity}.ckpt
data/
  compact/{msg,canopus}/{train,val,test}/
  {msg,canopus}/queries.jsonl
  msg/candidates_{mass,formula}.jsonl
  {msg,canopus}/{foam_seeds.jsonl,foam_seed_manifest.json}
  indices/subformula-msg/
  ms-gpt/{massspecgym,nplib1}/test/*.parquet
```

These paths are the download destinations expected by the example configurations.
The MIST catalog filenames are used as intended local destinations. Tokenizers and LoRA adapters are also external model assets; none
are copied into this repository. The decoder architecture YAMLs are small text
configurations included beside the model's runnable configurations.

## MS-GPT base and full model

The official release provides one shared conditional SAFE decoder and
benchmark-specific posterior-aligned LoRA adapters. Both model IDs use density
calibration and group querying, normally 20 queries × 5 samples:

- `ms-gpt-base`: load the conditional decoder without an adapter.
- `ms-gpt`: load that decoder plus a matching trained adapter.

A PEFT adapter directory must contain `adapter_config.json` and
`adapter_model.safetensors` or `adapter_model.bin`. Configuration alone is not
an adapter. Available `training_config.json` provenance is checked against the
benchmark and calibration. The loader validates the complete adapter tensor set
before merging; it never silently runs the base model when an adapter is missing.

The density-band JSON requires `benchmark` (`massspecgym` or `nplib1`),
`calibration_split: "train"`, `threshold_low` and `threshold_high`. Record the
encoder identity and calibration sample count as well. An adapter trained with
one MIST encoder/band is not automatically a valid replacement for another.
Use each official adapter with its corresponding encoder and training calibration.
To change the encoder, follow the official MS-GPT training procedure to produce
a matching adapter; changing only the encoder path does not preserve the paper's
model configuration.

The released MS-GPT density bands are included under `configs/ms_gpt/`. Its
default configurations use the historical MIST checkpoints distributed with
MS-GPT, not the newer ScaledMIST releases. The loader checks the encoder SHA-256
against calibration metadata, including when a posterior cache is supplied.
